# Natas & Bandit CTF Labs — Web Security and Linux Practice

A curated index of [Learn SecByte cybersecurity labs](https://learn.secbyte.org/ctf/) featuring Natas web security challenges and Bandit Linux command-line exercises.

This repository helps cybersecurity students, CTF participants, and ethical hacking learners find beginner-friendly entry points and progressively organized practice challenges.

## Introduction

Hands-on CTF exercises help learners develop technical investigation and problem-solving skills. Natas focuses on web security challenges, while Bandit emphasizes Linux command-line fundamentals and related security concepts.

Use this repository to navigate the listed labs, track your progress, and document the techniques and concepts you learn.

## Learning Path

1. Start with Natas Level 0 and follow the listed levels in order.
2. Observe how each challenge differs from the previous one.
3. Practice Linux command-line fundamentals through the Bandit exercises.
4. Document your investigation process and explain why each solution works.
5. Review relevant security concepts and repeat difficult exercises.

## How to Use the Labs

1. Open the challenge using its direct link.
2. Read the instructions and follow the lab's authorized scope.
3. Try solving each exercise independently.
4. Keep notes on commands, observations, and concepts.
5. Review your findings and identify ways to improve your methodology.
